# MixWasp

This is MixWasp, a full-stack web app built on Wasp (React, Node.js, and Prisma).

## Documentation

### Starter kit guides

Always fetch and verify your knowledge against the project's starter-kit documentation before taking on tasks, answering questions, or doing any development work in this project:

1. Fetch the documentation map from the [LLMs.txt index](https://docs.opensaas.sh/llms.txt). The map contains raw markdown file GitHub URLs of all documentation sections.
2. Fetch the guides relevant to the current task or query from those raw.githubusercontent.com URLs directly - do NOT use HTML page URLs.

### Wasp

If the starter-kit docs fail to provide enough information about a certain feature, check the Wasp docs [LLMs.txt index](https://wasp.sh/llms.txt).
